# causal-web

A memstream tape viewer. Drop in a `.jsonl` tape and the page threads utterances, actions and observations into causal lines via `refs`, then validates the tape in-page. Zero runtime dependencies, fully client-side — files never leave your machine.

## Run

```sh
bun install
bun run serve   # → http://localhost:3777 (loads examples/sample.jsonl)
```

Open `http://localhost:3777/?tape=examples/other.jsonl` to load a specific tape.

Other scripts: `bun test` (validation unit tests), `bun run check` (tsc), `bun run build` (emits `dist/main.js`).

## In-page validation

- every line parses as JSON (bad lines located by line number)
- schema: `v = 1`, required fields, `kind`/`from_kind` enums
- `seq` increments from 1 without gaps
- ids unique
- ids are ULIDs whose embedded timestamp matches the `ts` field (mirrors det_seam's `Entropy::ulid(now_ms)`)
- `ts` monotonically non-decreasing (same-millisecond runs are legal — observed on live tapes)
- no dangling `refs`
- every observation cites an action
- every tool action is answered by at least one observation
- single session per tape

`examples/sample.jsonl` is generated by `scripts/gen-sample.ts` (`bun scripts/gen-sample.ts`); its ULID timestamps match `ts` and it passes all checks.
