# an-agent 约束合同

本文是核对合同，不是实现说明书。

核对只在用户明确说「核对」时进行。核对方式：针对下列性质写测试，或给出数学证明。未到其切片的性质，现状是「未实现」，不是「违反」。

当前切片：最平庸的单 agent。后面的性质全部推迟，但不得写出与它们直接冲突的内核（例如可改写的 log 冒充审计）。

---

## 命名

- **agent**：系统里的行动主体。曾用名 PC，仅命名，无 D&D 语义。
- 本项目与 Dungeons & Dragons 无关。禁止把角色、阵营、战役、DM 等当作设计概念。

---

## 建造顺序

1. 单进程、单 agent：市面普通 agent 的核心循环（对话、工具、基本约束）。
2. 同框架多 agent 协作。
3. 跨机器、网络上的分布式 agent。
4. 审计与溯源（每个动作可追到缘由）。
5. 撤回 / 回滚：log 不回滚；state（宏观状态、上下文、本 agent 操作过的文件与内容）可回到先前时刻。
6. DSH 的时间可组合性与空间可组合性：不停机增减功能。

不得跳步把 2–6 做进第 1 刀。第 1 刀可以留不冲突的钩子（例如只追加、不可改写的记录），但钩子本身不能长成子系统。

---

## 已钉性质

核对应逐条对照。状态：`切片1` = 当前要做；`推迟` = 未到切片，不实现也不假装已满足。

### P1 — 平庸 agent 核心循环（切片1）

系统首先是一个普通 agent：接受输入，调用模型，执行工具，产出回复，受基本约束（权限/沙箱一类的硬限制，具体集合在切片1里再定）。

不做：多 agent、跨机器、回滚、热插拔、完整因果图。

### P2 — Log 不可回滚（推迟，但内核不得与之冲突）

存在一类 log。

- 只追加。
- 回滚 state **不得**删除、改写、截断 log。
- 回滚本身必须作为一条 log 记录存在。
- Log 是审计与溯源的真理源。

### P3 — State 可回滚（推迟）

可回滚的 state 至少包括：

- 宏观状态
- 模型上下文
- 本 agent 操作过的文件和内容

回滚到时刻 T 之后，上述 state 等于 T 时刻的 state。

Log 全文与当前 state 可以不一致。解释当前 state 的唯一合法方式：顺着 log 读到末尾，并应用其中的回滚记录。

### P4 — 每个动作可追到缘由（推迟）

每个动作在 log 中能追到缘由。缘由属于：用户意图、其他 agent 的消息、自身先前状态、当时有效的约束。这是因果记录，不是「调用了工具 X」这种事件 dump。

### P5 — 同框架多 agent（推迟）

至少支持同一框架内多个 agent 协作。协作对象是对等 agent，不是一次性的内部 worker（后者若存在，不得顶替这条）。

### P6 — 分布式（推迟）

agent 可以在不同机器上，经网络连接。身份是否可迁宿主：未定，第一刀不做。

### P7 — DSH 时空可组合性（推迟，最后做）

- **时间可组合性**：卸掉一个组件时，它对共享 context 造成的效应能被完全撤销（与 P2+P3 同方向）。
- **空间可组合性**：组件在共享 runtime space 中按需建立/解除依赖；不停机增加或减少功能。

进程内热加载 ≠ 跨机器的 space。跨机器是另一件事，到该切片再定。

### P8 — 不可逆外部效应（已钉边界）

本地可追踪 state（含本 agent 操作过的文件）可以回滚。HTTP、邮件、对端已执行动作等外部效应：log 记录，不保证世界回到 T。禁止把「文件可回滚」写成「一切效应可回滚」。

## 未钉（核对前必须先钉）

### Q2 — 回滚点之后的外来文件改动

本 agent 操作过的文件，在 T 之后被用户或其他进程改过，回滚到 T 时：

- **A.** 硬回到 T，覆盖后来的外来改动。
- **B.** 只逆本 agent 的效应，保留外来改动；冲突则失败或标脏。
- **C.** 若有外来改动，拒绝回滚。

未选。文件回滚切片开始前必须选定。不得在未选定的情况下实现文件回滚。

### Q-identity — agent 与宿主

agent 是绑在单机进程上的实例，还是可迁宿主的持续身份：未定。分布式切片开始前必须选定。

## 核对协议

用户说「核对」时：

1. 只核对本文件中的性质，不临时发明新标准。
2. 对已进入实现的性质：测试或证明。测试必须失败于违反、通过于满足。证明必须写明假设与结论。
3. 对标记为「推迟」且尚未实现的性质：报告「未实现」，列出与之冲突的现有代码（若有）。冲突视为缺陷。
4. 未钉问题（Q2、Q-identity）没有实现、也就没有核对对象。

## 切片1 范围（当前）

做：一个最普通的单 agent。

不做：多 agent、网络、回滚、DSH 组合、完整因果溯源、文件快照。

允许：极小的只追加记录（若加，必须不可改写），仅为以后不冲突；不加读取、回放、回滚 API。

- Bun：运行、装包、测试
- 应用模型：DeepSeek，经 `ModelClient` 注入，默认 `deepseek-v4-flash`
- 形态：纯函数核心 + 薄 CLI
- 工具默认空列表，循环支持注入工具
