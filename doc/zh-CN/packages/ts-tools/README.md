# ts-tools

[English](../../../../packages/ts-tools/README.md) · 中文译文，以英文为准。 · [中文目录](../../README.md)

TS工具探测包：TypeScript工具能否与Rust内置函数拥有相同的 `Tool` 特性？

**协议（stdio，一次性）：** 从标准输入读取一个JSON对象，向标准输出写入一个JSON对象，进程退出。日志输出到标准错误，而不是标准输出。

**运行时：** bun（无需安装步骤，无需node_modules —— 纯脚本）。

**诚实说明：** TypeScript子进程拥有环境权限 —— 声明的效果是一个承诺，而非连接图（不同于rhai沙箱，其中宿主函数白名单机械地定义了效果边界）。信任层级与MCP相同。

**状态：** 探测中。当前描述符验证器拒绝一个 `ts` 构造函数 —— 这种拒绝是实验结果的一部分。
