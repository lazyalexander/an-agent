# 一个代理监督

[English](../../../../crates/an-agent-supervision/README.md) · 中文译文，以英文为准。 · [中文目录](../../README.md)

与传输无关、进程本地的审查状态。依赖于 `an-agent-semantic`，
而不是核心、磁带、工具、磁带加载器或宿主交互循环。

追踪实时实例、监督者关系、挂载身份、权限纪元、待处理审查以及精确的一次性批准绑定。它不执行任何IO操作，不启动任何工作，也不会扩展资源上限。

依赖变更请求引用被隔离的边界证据。这些请求可以被查阅、拒绝，或通过请求新的工作来解决，但绝不能使用ApproveOnce来解决。解决不会提升旧结果，也不会自动重试。

可信调用者验证主体，提供新的实例ID，序列化状态转换，验证硬性权限，并持久化证据。批准证据必须在激活之前成功；撤销和消费会在可信赖证据交付之前移除权限。一个序列化的请求是历史证据，而不是权限令牌。

独立测试在没有磁带或核心运行时的情况下运行状态机。核心集成测试运行真实的边界适配器。现有的公开审查类型通过 `an_agent_core::control` 重新导出保持可用。

这个账本是受信任的内存状态，而不是持久化的授权服务。关闭的请求ID在整个生命周期内都会被保留。重启需要新的绑定和审查；没有从历史中自动恢复权限的功能。
