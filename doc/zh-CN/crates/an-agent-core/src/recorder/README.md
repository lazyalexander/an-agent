# 录音员

[English](../../../../../../crates/an-agent-core/src/recorder/README.md) · 中文译文，以英文为准。 · [中文目录](../../../../README.md)

文件工作区的管理者。不是宿主面，也不是进程。

**准入规则：** 仅有录音员可以在此树上生成工作者。其面向世界的权限为拒绝。生成、邮件和链接在此处是动词，而非工具。一个视图是一个已命名的链接ID列表，这些链接ID已经存在于其磁带上。每个工作者都有一个子工作区。关闭它会发布一个视图，或询问当两个真实名称声称同一路径时的情况。录音员不写入文件字节。`recover` 从磁带重建投影。

**依赖项：** `agent`, `seat`, `memstream`, `act`。永不使用：`control`，工作区CAS存储。
