# 主体

[English](../../../../../../crates/an-agent-core/src/principal/README.md) · 中文译文，以英文为准。 · [中文目录](../../../../README.md)

代理身份：`AgentCard`（模型规格 + 提示 + 工具授权 + 内核引用），一个只追加内容寻址的注册表，以及一个卡片驱动的工厂。

**准入规则：** 身份与构造。无运行时状态，无记忆，无密钥 —— 一张卡片声明的是记忆 *访问权限*，而非内容本身。演化是取代：新卡片，`supersedes` 边缘，旧卡片保持不变。

**依赖项：** `act`（工具特性/标签），`det_seam`。构造器由外部传入；此 crate 不注册工具。绝不会：循环，HTTP。

**不在此处：** 实际代理，座位，宿主界面，记录器，工具实现，ReAct 循环，以及模型客户端。`agent::spawn_with` 将 `BuiltAgent` 绑定到一个私有目录。
