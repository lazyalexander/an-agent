# an-agent-semantic

[English](../../../../crates/an-agent-semantic/README.md) · 中文译文，以英文为准。 · [中文目录](../../README.md)

垂直语义平面：传输中立的声明，具体尝试，版本绑定的决策，授权和执行收据。它不包含工具、磁带、工作区、卷轴、宿主句柄或交互循环。

**准入规则：** 每个权威都是一个独立的声明。只有当所有提供的声明覆盖相同的主体、操作、资源和极性时，才允许具体尝试。没有声明则拒绝。适配器提供所有必需的权威。授权绑定执行ID、主体、能力、事实修订和输入引用，精确地；`Grant::matches`检查绑定，而不是真实性或一次性消费。收据记录成功、失败或未知的执行情况，并附带授权和证据；未知状态不允许安全重试。

**边界规则：** 业务crate将领域操作转换为语义尝试。此crate从不导入其词汇或安排、取消、卸载或联系代理。其决策是一种评估，而不是中断命令。受信任的执行边界拥有句柄并强制执行硬性上限；控制层停止被阻塞的操作，并向绑定宿主的监督者发送审查请求。仅有观察并不等于执行。

**声明检查器：** `assess_contract`接受一个尝试、一个边界配置文件和与精确输入事实绑定的角色标记声明。它返回允许、拒绝或未知，并附带发现和明确的覆盖限制，而不是授权。缺少角色、重复角色、缺失/未绑定的证据和未覆盖的操作无法产生允许。已知的违规行为即使其他证据不完整仍保持拒绝。配置文件和声明角色来自受信任的适配器，而不是自述的YAML。同一个纯函数支持离线预检和运行时比较，无需磁带或宿主。它检查声明，而不是任意程序行为。

**依赖检查器：** `assess_dependencies`区分授权、执行前提条件、历史上下文和派生产物。当前生成的要求与固定证据不同：较新的修订不会抹去历史，而撤回会使得即使固定证据也失效。缺失或模糊的观察返回未知，而不是有效。这个纯评估不包含授权或安排指令；适配器提供权威的观察。核心检查在准入前和发布响应前对输入进行建模，隔离过期/未知结果，并在原始范围仍然有效时请求监督者审查。它不会取消外部调用或撤销调用。

**当前适配器：** 核心记录允许和拒绝的交付决策，并建模完成决策。模型尝试绑定卡片、挂载的声明、交付注册、工作区成分和保留的应用请求。被拒绝的交付或模型调用返回一个审查请求，而不卸载正文。终端模型观察包含收据。新的合同评估以影子模式记录在现有决策旁边；协议、差异和不完整输入是明确的。现有准入仍决定执行。卡片配置的端点不是独立的出口授权，且交付配置文件不覆盖原生正文的隐藏IO。语言级别的静态分析、外部来源、幂等性、重放执行和操作系统沙箱强制执行仍为后续切片。

**依赖项：** `serde` 仅。产品crate可能依赖此crate；此crate从不依赖它们。策略语言、存储、传输、交互和观察导出器仍为可替换的适配器。

**执行术语：** 一个 silk 现在是 spool 的一个内部可调用步骤。
spool 尝试拥有执行隔离和生命周期；语义评估不会为每个 silk 分配一个后端。历史 Silk 通信记录保留其原始模式和含义。供应商特定策略和 OpenShell 状态在宿主边界处进行转换，绝不会导入到此 crate 中。
